-all argument like
| Argument      | Purpose                                |
| ------------- | -------------------------------------- |
| `where`       | Filter rows                            |
| `order_by`    | Sort results                           |
| `limit`       | Return only the first *N* rows         |
| `offset`      | Skip the first *N* rows                |
| `distinct_on` | Return one row for each distinct value |
| `cursor`      | Pagination (less common)               |
