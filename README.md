# GraphQL Profile

A personal profile dashboard built with **GraphQL** that displays your Zone01 learning statistics. The application authenticates users with JWT, fetches their data from the GraphQL API, and presents it through a clean interface with interactive SVG charts.

> **Live Demo netlfy:** https://grpah-ql.netlify.app/
>**Live Demo github-pages** https://hamzaerrhh.github.io/graphQl/

> **Note:** This project is only accessible to **Zone01 Talent** users with valid platform credentials.

---

## Overview

This project demonstrates how to:

- Authenticate users using **Basic Authentication** and **JWT**
- Query a **GraphQL API**
- Display personal profile information
- Visualize statistics using **SVG graphs**
- Build a responsive frontend using only HTML, CSS, and JavaScript

---

## Features

- Secure login (username/email + password)
- JWT authentication
- Personal profile information
- XP statistics
- Grades and audit information
- Interactive SVG charts
- Logout functionality

## What You'll Learn

## Running the Project

Since the project is a static website, simply serve the files using a local server.

### Option 1 — VS Code Live Server

Open `index.html` with the **Live Server** extension.

### Option 2 — Python

Python 3:

```bash
python -m http.server 8000
```

Then open:

```
http://localhost:8000
```
